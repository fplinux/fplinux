FPLinux for Maxvi K15n4G

Read docs/guides/STANDALONE.md before connecting the phone. It contains the
host requirements, USB setup, checksum, loader-first and reconnect procedures.
Hold the left soft key when the loader asks for the powered-off phone.

This target starts Linux in RAM. The phone provides USB networking, SSH access
and read-only physical NAND backups. Display, keypad, audio and Bluetooth
behavior have not been qualified; use the phone through its USB session.

To end the session, disconnect USB. If a battery is installed, remove and
reinsert it before booting the phone normally.
