itel Neo R60+ (IT9310) radio firmware diagnostic

This test boots Linux into RAM, reads the radio ID over SDIO1, then starts the radio firmware from your saved phone data and requests its Wi-Fi firmware information. The test takes the radio back down and restores its settings when done. Wi-Fi, Bluetooth and FM are unavailable in this test build.

1. In Command Prompt, open the extracted folder and run:

   Run.cmd run itel-neo-r60-plus

   Use your existing phone data. To prepare it from a backup you already have, add --from-dump "C:\path\to\nand.bin". Cancel if the launcher asks to read a new backup.

2. Wait for the USB prompt. Hold the left soft key and green call key together, then connect the powered-off phone. Leave the SSH window open when it appears.

3. Paste this command once into the phone's SSH prompt:

   p=/sys/bus/platform/devices/itel-radio-probe; echo 1 > "$p/boot" && { for i in $(seq 1 135); do grep -q cleanup_done=1 "$p/result" && break; sleep 1; done; cat "$p/result"; }

4. Send the full output from step 3, even if it reports an error. The result includes the stage reached, firmware and calibration checks, the ready flag, the information response and cleanup. If step 1 fails, send its runtime.log and run.json. Keep USB connected until the probe finishes. Use poweroff in the SSH window when done.
