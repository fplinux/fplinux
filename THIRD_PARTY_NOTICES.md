# Third-party notices

## License

Original FPLinux code and documentation are licensed under `GPL-2.0-only` unless an individual file carries a different SPDX identifier. Downloaded and third-party components retain their own licenses.

## Where versions are recorded

The corresponding source snapshot records exact versions, URLs, commits and hashes in `sources.lock.toml`, `environment.lock.toml`, `alpine.lock.toml`, package locks, host-runtime locks, platform loader asset locks, target manifests and the platform U-Boot source lock. Binary archives carry the resolved asset lock as `assets.lock.toml` for a single model or `assets/<target>.lock.toml` for a release with model selection. Archives also include content receipts and `SHA256SUMS`. Aport `APKBUILD` files refer to upstream originals declared in `sources.lock.toml`. The build resolves these references into local files with SHA-512 checksums. Checksums for checked-in package sources remain in the APKBUILD.

The native build environment uses LLVM, Clang, LLD, compiler-rt and libunwind 23.1.6 under Apache-2.0 with the LLVM exception. It also uses SPIR-V Headers and Tools from Vulkan SDK 1.4.357.0 and SPIRV-LLVM-Translator 23.1.1. The locally built toolchain package installs the upstream license notices under `/usr/share/licenses/fplinux-build-toolchain`.

The TyrQuake 0.71 source archive is pinned in `sources.lock.toml`; the APKBUILD records SHA-512 sums for local sources and patches. Its FLAC, MP3 and WAV decoders use MIT-0; the minimp3 portions of the MP3 decoder use CC0-1.0; and stb_vorbis uses MIT. Quake PAK files are separate game data. They are not part of the source tree, root filesystem, RAM image, source companion or release archive.

The website's Noto Sans font retains its copyright and Open Font License
notice in `site/public/fonts/OFL.txt`. The generated offline site carries the
font and its notice.

Linux and Windows archives include Python 3.15.2. Linux archives include OpenSSH 10.3p1 and Windows archives include Win32-OpenSSH 10.4.0.0p1-Preview. Their included license directories retain the notices for these runtimes and their libraries. The Windows driver helper uses libwdi 1.5.1 under LGPL-3.0-or-later and includes its GNU GPL and LGPL license texts. It installs the WinUSB driver included with Windows 10 and 11.

Qin runtime archives include ext4 1.4.1, cachetools 8.0.2 and crcmod 1.7 for reading selected files from a saved eMMC image. These packages use the MIT license; their original notices are included under `licenses/phone-data/`, and their pinned originals are included in the matching source companion.

The Git tree does not contain `spreadtrum_flash` source, `spd_dump`, `fphelper_t117` or `t117_fdl1.bin`. Setup downloads and verifies exact locked inputs under the selected working data directory (`.data/` by default). Builds use the prepared inputs without downloading them.

The contributor board-report command uses `fphelper_t117` to read tables from the owner's phone backup. This tool is not part of the runnable archives.
