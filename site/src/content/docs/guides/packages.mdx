Optional applications come as APK files built together with the FPLinux image. Each build and extracted ZIP includes an `apks/` directory with the optional packages and their additional required libraries. Install them manually on the running phone; the launcher does not install them. Check your phone's [application support](/fplinux/phones/#application-support) before choosing a package.

## How long a package stays

| System | After installing |
| --- | --- |
| RAM system | The package is lost when the phone powers off. |
| [microSD system card](/fplinux/guides/microsd-system-card/) | The package stays until you remove it. |

A card used only for personal files does not make a RAM installation permanent. Before cutting power to a system card, shut it down as described in [Power](/fplinux/use/power/).

## Install a package

Copy the application's APK and any required library or font APKs to the phone. Pass them together in one `apk add` command so the phone can resolve the dependencies offline. Use the packages from the same build as the running image; you do not need to search an Alpine mirror for matching libraries.

The example below installs [TyrQuake](/fplinux/apps/tyrquake/) (`fplinux-tyrquake.apk`) on a Nokia 3210 4G. It needs no additional library APKs on that image; its application guide explains the required game data. General USB file transfer requires Linux; the Windows launcher supports SSH but does not copy files. From Windows, use a supported data card to supply the APKs and run `apk` in the phone's SSH shell.

<Tabs syncKey="source">
<TabItem label="Source checkout">

The APKs are in the `apks/` folder of the output directory printed by `./fplinux build`. Replace `<output>` with that directory:

```sh title="PC"
./fplinux console nokia-ta1618 --upload \
  <output>/apks/fplinux-tyrquake.apk /tmp/fplinux-tyrquake.apk
./fplinux console nokia-ta1618 --exec \
  'apk add --no-network --allow-untrusted --force-non-repository /tmp/fplinux-tyrquake.apk'
```

Use the target, profile and build type of the running session. For a system card, pass its `--profile` to both commands; see [system-card profiles](/fplinux/guides/microsd-system-card/).

The install command reads only the named local APKs and disables network access. `--allow-untrusted` permits these local files; it does not verify their origin. Use only the matching APKs supplied with your image.

## Remove a package

Close the application through **Open applications** first. Remove it by its package name, without `.apk`, in the phone's SSH shell:

```sh title="Phone"
apk del fplinux-tyrquake
```

The same command can be run from Linux with `./fplinux console nokia-ta1618 --exec 'apk del fplinux-tyrquake'` or `sh Run.sh console --exec 'apk del fplinux-tyrquake'`. Use the target of your connected phone.

## Java and MRE

Install `fplinux-phoneme.apk` for `.jar` files and `fplinux-mre.apk` for `.vxp` files. Include the required library APKs from the same `apks/` directory in the install command. MRE also needs `fplinux-font-terminus-8x16.apk` if the font is not installed. After installation, open your files in [Files](/fplinux/use/files/); see [Java and MRE applications](/fplinux/apps/java-and-mre/) for controls and settings.

## Full curses libraries

`fplinux-ncurses-curses.apk` adds the full curses, menu, form and panel libraries to the RAM system. The microSD system card already includes them.
