Optional applications come as APK files built together with the FPLinux image. Install them into a running phone; you do not need a new load. Each [application page](/fplinux/apps/) names its APK file, its package name and how to start it. Check your phone's [support status](/fplinux/phones/#support-status) before choosing an application.

## How long a package stays

| System | After installing |
| --- | --- |
| RAM system (default) | The package is gone when the session ends. |
| [microSD system card](/fplinux/guides/microsd-system-card/) | The package stays until you remove it. |

Before cutting power to a system card, shut it down as described in [Power](/fplinux/use/power/).

## Install a package

Copy the APK to the phone, then install it. This example installs ARMADA (`fplinux-showcase.apk`) on a Nokia 3210 4G.

RAM ZIPs do not include optional APKs. Build the matching source revision on Linux and take the APK from the build's `apks/` directory, or ask the person who supplied your ZIP for that matching APK. Linux system-card exports already include an `apks/` directory. The transfer commands below require a Linux PC; the Windows launcher does not support file transfer.

<Tabs syncKey="source">
<TabItem label="Source checkout">

The APKs are in the `apks/` folder of the build directory that `./fplinux build` printed after `output:`. Run the commands from the checkout and replace `<output>` with that path:

```sh title="PC"
./fplinux console nokia-ta1618 --upload \
  <output>/apks/fplinux-showcase.apk /tmp/fplinux-showcase.apk
./fplinux console nokia-ta1618 --exec \
  'apk add --no-network --allow-untrusted --force-non-repository /tmp/fplinux-showcase.apk'
```

Use the target, profile and build type of the running session. For a microSD system card, pass the selected `--profile` to both commands; see [system-card profiles](/fplinux/guides/microsd-system-card/).

</TabItem>
<TabItem label="Linux RAM ZIP">

Run from the extracted archive. Replace the local path with the APK you obtained for this build:

```sh title="PC"
sh Run.sh --reconnect --upload \
  /path/to/fplinux-showcase.apk /tmp/fplinux-showcase.apk
sh Run.sh --reconnect --exec \
  'apk add --no-network --allow-untrusted --force-non-repository /tmp/fplinux-showcase.apk'
```

</TabItem>
<TabItem label="Linux system-card export">

Run the commands from the extracted archive directory:

```sh title="PC"
python3.14 -I fplinux.py run --reconnect --upload \
  ./apks/fplinux-showcase.apk /tmp/fplinux-showcase.apk
python3.14 -I fplinux.py run --reconnect --exec \
  'apk add --no-network --allow-untrusted --force-non-repository /tmp/fplinux-showcase.apk'
```

</TabItem>
</Tabs>

## Remove a package

Stop the application first. Remove it by its package name, without `.apk`:

<Tabs syncKey="source">
<TabItem label="Source checkout">

```sh title="PC"
./fplinux console nokia-ta1618 --exec 'apk del fplinux-showcase'
```

</TabItem>
<TabItem label="Linux RAM ZIP">

```sh title="PC"
sh Run.sh --reconnect --exec 'apk del fplinux-showcase'
```

</TabItem>
<TabItem label="Linux system-card export">

```sh title="PC"
python3.14 -I fplinux.py run --reconnect --exec 'apk del fplinux-showcase'
```

</TabItem>
</Tabs>

## Full curses libraries

`fplinux-ncurses-curses.apk` adds the full curses, menu, form and panel libraries to the RAM system. The microSD system card already includes them.

## Package sources

Install only the APKs built with your image. The install command above uses local APK files and disables network access. The phone also has `wget` with a certificate bundle for HTTP and HTTPS downloads; a download over HTTPS does not make an APK trusted.
