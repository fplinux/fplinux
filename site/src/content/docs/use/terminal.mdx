Open **Terminal** from the application catalog. It runs Bash alongside the other [phone applications](/fplinux/use/session/), with command editing, completion, history, reverse search and scrollback. The shell uses the application's account. Use the [USB shell](/fplinux/use/connect/) for commands that require administrative access or a full computer keyboard.

Terminal uses the interface's shared font and fits its rows and columns to the available screen. A narrow screen shows fewer columns; long commands wrap. Terminal does not change the font of the Linux text console.

## Type with the keypad

Press a digit repeatedly to choose a character, then pause or press another digit to send it. The pending character appears at the cursor. The title shows the input mode and any modifiers armed for the next phone key.

| Key | Action |
| --- | --- |
| Digits | Multi-tap text, or digits in `123` mode |
| <Key>1</Key> | Punctuation |
| <Key>0</Key> | Space |
| <Key>\*</Key> | Change letter case, including a pending letter |
| Hold <Key>\*</Key> | Switch between digits and letters |
| <Key>#</Key> | Cancel a pending character, otherwise Backspace |
| Hold <Key>#</Key> | Clear the command line at the Bash prompt |
| <Key>Centre</Key> | Enter |
| <Key>Dial</Key> | Tab completion |
| D-pad | Arrow keys; scroll earlier output while scrollback is open |

The on-screen **Clear** command cancels a pending letter, otherwise clears armed modifiers, otherwise sends Backspace. Holding <Key>#</Key> clears the Bash command line only when Bash owns the terminal; it does not clear input inside another program.

The initial keypad language follows **Settings → Input**. Choose **Options → Language** to change it for this terminal.

Holding a D-pad key repeats its arrow action. External keyboards repeat the keys allowed by their layout, using the graphical session's delay and rate. Opening Options, switching screens or hiding Terminal stops the held repeat; press the key again after returning.

## Options

Use the soft-key labels to open **Options**, move with <Key>Up</Key> and <Key>Down</Key>, and choose an item with <Key>Centre</Key>:

- **Modifiers** selects Ctrl, Alt and Shift for the next phone key or committed letter. Mark the required modifiers and choose **Done**; **Back** keeps the previous selection.
- **Symbols** inserts a literal symbol.
- **Special keys** sends Escape or F1–F12.
- **Language** chooses the keypad language from the installed input languages.
- **Scrollback** shows earlier output.
- **Interrupt Ctrl+C**, **End input Ctrl+D** and **Search Ctrl+R** send those shortcuts to the running program.
- **Help** explains the controls on the phone.
- **Exit** closes the terminal and its shell.

A pending letter waits while a menu, another screen or the lock covers the terminal. Returning to it gives the letter a fresh pause before it is sent. A <Key>\*</Key> or <Key>#</Key> gesture held into that transition is cancelled.

## Scrollback and history

Choose **Options → Scrollback** to read earlier output. <Key>Up</Key> and <Key>Down</Key> move one line; <Key>Left</Key> and <Key>Right</Key> move one page. The title shows the number of lines above the live view. **Back** or typing returns to live output.

At the Bash prompt, <Key>Up</Key> and <Key>Down</Key> choose earlier commands; **Search Ctrl+R** searches command history. History is stored with the application's state. In a RAM boot it disappears when the phone powers off; a supported persistent system root can retain it.

## Minimize, lock and close

The [shared application controls](/fplinux/use/session/#home-and-applications) apply to Terminal. **Minimize** returns to Home and keeps the shell and its programs running. Open Terminal from **Tasks** to continue. Locking or turning off the screen also leaves programs running.

**Close**, **Tasks → Close app** and **Options → Exit** terminate the shell and its terminal jobs. Save files before closing. Exiting Bash, including Ctrl+D at an empty prompt, closes Terminal. Returning Home alone does not end the shell.

## Keyboards

External keyboards use the session's installed layouts and their own Ctrl, Alt and Shift keys. <Key>Alt</Key>+<Key>Shift</Key> switches layouts; see [keyboard support](/fplinux/use/connect/#type-with-your-computers-keyboard) for your phone. Keyboard Escape and Enter are sent to the running terminal program. F13 and F14 remain ordinary function keys.

Use <Key>Shift</Key>+<Key>PageUp</Key> and <Key>Shift</Key>+<Key>PageDown</Key> for scrollback. <Key>Ctrl</Key>+<Key>Esc</Key> returns to Home while retaining the terminal in Tasks.
