Open **Calculator** from the [application catalog](/fplinux/use/session/#home-and-applications). Enter a number, choose an operation with the D-pad, enter the next number and press <Key>Centre</Key> to calculate.

| Key | Action |
| --- | --- |
| Digits | Enter a number |
| <Key>Up</Key> | Add |
| <Key>Down</Key> | Subtract |
| <Key>Left</Key> | Multiply |
| <Key>Right</Key> | Divide |
| <Key>Centre</Key> | Calculate the result |
| <Key>\*</Key> | Enter the decimal separator |
| <Key>#</Key> | Change the sign |
| **Clear** while entering a number | Delete a character; hold to reset the calculation |
| **Reset** after a result or error | Reset the calculation |

Operations apply from left to right. For example, `2 + 3 × 4` gives `20`. Each entered number accepts up to 12 digits. If another digit cannot fit, **Maximum 12 digits** appears above the number; delete a digit to continue. Division by zero and a result outside the numeric range have separate explanations above **Error**. Entering a new number starts another calculation.

An external keyboard accepts digits, `+`, `-`, `*`, `/` and `=`; <Key>Enter</Key> calculates, and <Key>Backspace</Key> deletes. A dot or comma enters the decimal separator, and `x` also multiplies.

Use **Back** to save and leave without clearing the calculation. While entering a number, choose **Options → Back**; after a result or error, **Back** is on the left soft key. The [shared application controls](/fplinux/use/session/#home-and-applications) also return Home or close Calculator. A failed save keeps the calculation available and offers the [shared save choices](/fplinux/use/session/#saving-and-storage-errors). In a RAM boot, saved application state lasts until the phone powers off; see [Keeping data](/fplinux/use/session/#keeping-data).
