FPLinux provides shared interfaces for the display, input, sound, connectivity, storage and power. Their implementations differ between [UMS9117](/fplinux/platforms/ums9117/) and [SC9820E](/fplinux/platforms/sc9820e/). The guides explain how to use each function; availability and limits on one exact phone belong to its [support checklist](/fplinux/phones/).

## Status meaning

**Implemented** means FPLinux provides a shared platform implementation of the interface or application. It may still require hardware fitted to the selected phone or an optional package. **Not implemented** means there is no shared implementation; an individual target can provide its own.

Platform status describes FPLinux code only. A platform implementation does not establish that every phone has the required component, board wiring or working driver path. Each phone records its own hardware, stock-firmware functions and FPLinux results; none of these values is inherited from the platform.

For example, BQ 2830L supplies its own external-radio Wi-Fi implementation. This does not give Wi-Fi to other UMS9117 phones or make it a shared UMS9117 feature.

The [phone status legend](/fplinux/phones/#support-status) explains **Verified**, **Partial**, **Not tested** and **Unsupported** for one model. **Stock: Available** describes the original firmware, not FPLinux. Source code, compilation and platform status do not establish a physical result. A phone can have a microphone while its FPLinux recording path remains untested.

## Not implemented

Entries marked **Not implemented** have no shared platform implementation. That status does not establish whether a phone contains the hardware or provides a target-specific implementation. Check the selected phone's checklist before choosing a model or planning a port.

## Choose or bring up a phone

Use the [phone catalog](/fplinux/phones/) to compare models, then read the exact phone page for its boot key, supported storage and safe way to end a session. For an unlisted model, follow the [new-phone checklist](/fplinux/porting/checklist/) and [headless bring-up](/fplinux/porting/bring-up/).
