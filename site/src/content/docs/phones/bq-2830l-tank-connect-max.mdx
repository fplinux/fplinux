## Before you start

The RAM launcher prepares [device data](/fplinux/guides/device-data/) from this same handset for its audio settings and the external radio's firmware and configuration. Do not use another phone's data.

## Boot key

<PhoneBoot />

## Controls and storage

[Terminal](/fplinux/use/terminal/) describes the shared controls. Insert a microSD data card before boot and leave it installed while the phone is powered; hot-swap is not supported. RAM files disappear when power is removed.

## Power

Stop active radio connections before sleeping. Use the shared [Power](/fplinux/use/power/) interfaces only within the checklist conditions.

## End the RAM session

[Unmount data cards](/fplinux/use/power/#unmount-data-cards) before disconnecting USB. If a battery is fitted, remove and reinsert it before booting normally.

## Hardware controls and limits

The backlight is `/sys/class/backlight/bq-2830l-backlight`. Use [Display and lights](/fplinux/use/display-and-lights/) for its controls.

:::caution

Concurrent camera capture and hardware rotation require one capture buffer and a separately saved frame. Do not use rotation with two active capture buffers. See [Camera](/fplinux/use/camera/) for shared resource rules.

:::
