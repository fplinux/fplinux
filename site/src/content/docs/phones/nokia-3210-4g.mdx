## Controls

The red handset key, <Key>Red</Key>, is the power key.

| Key | Action |
| --- | --- |
| <Key>Red</Key>, short press | Wakes the phone from suspend. |
| <Key>Red</Key>, held for five seconds | Powers the phone off; see [Power](#power). |
| <Key>8</Key> and the other keypad keys | Do not wake the phone. |

See the shared keypad bindings and application keys in [Terminal](/fplinux/use/terminal/).

## Storage

- microSD data cards can be FAT32 or ext4, read and write. You can remove and insert an unmounted card while Linux runs.
- The [microSD system card](/fplinux/guides/microsd-system-card/) works; it stays installed while Linux runs.
- File transfer from a PC can write to RAM or to a mounted writable microSD card.

## Power

Battery-only power-off works: disconnect USB and any charger, then hold <Key>Red</Key> for five seconds. FPLinux refuses to power off while external charger power is present. [Power](/fplinux/use/power/) describes the interface.

## End the session

With a battery installed, use [power-off with the red key](/fplinux/use/power/#power-off-with-the-red-key). Without a battery, follow [End the session safely](/fplinux/use/power/#end-the-session-safely) for a RAM session, or [USB-powered shutdown](/fplinux/use/power/#shut-down-a-system-card-on-usb-power) for a microSD system card.

## Hardware details and limits

- **Backlight**: `/sys/class/backlight/ta1618-backlight` with the raw range 0–20, starting at 15. The spacing of the intermediate system brightness levels has not been fully checked; see [Display and lights](/fplinux/use/display-and-lights/).

:::caution

Finish camera capture before using hardware image rotation. Concurrent ROTA use can cause a camera frame error on this phone.

:::
