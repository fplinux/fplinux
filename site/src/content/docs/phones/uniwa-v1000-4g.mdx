## Before you start

The RAM launcher prepares [device data](/fplinux/guides/device-data/) from this same handset for Bluetooth, FM radio and its audio settings. Do not substitute another phone's data.

Use the authenticated SSH connection over USB-NCM described in [Connect from the PC](/fplinux/use/connect/) for command input while full keypad operation is unverified. On-phone image presentation is unverified.

## Controls

The held <Key>D-pad Up</Key> key is detected by Linux. The other physical keys and complete keypad input are unverified.

## Storage and power

Insert a microSD card before boot and keep it installed throughout the powered session; hot-swap is not supported. Every start, including a [microSD system card](/fplinux/guides/microsd-system-card/), requires the PC loader. RAM files disappear when power is removed.

Use the shared [Power](/fplinux/use/power/) interfaces within the checklist conditions. For sleep with a microSD system card, make the system root read-only and stop active peripherals first. Sleep with a writable root or a battery is unverified.

Before removing power, [unmount data cards](/fplinux/use/power/#unmount-data-cards). With a microSD system card, use [system-card shutdown on USB power](/fplinux/use/power/#shut-down-a-system-card-on-usb-power) and confirm that the system root is read-only before cutting power.

## Hardware controls and limits

Use [Display and lights](/fplinux/use/display-and-lights/) for brightness, keypad illumination and vibration, within the checklist conditions. Torch use is unverified.
