## Before you start

Prepare [device data](/fplinux/guides/device-data/) from this same handset for its board maps, Bluetooth, FM radio and fitted audio. Do not use another phone's backup or prepared data.

Use the authenticated USB shell described in [Connect from a computer](/fplinux/use/connect/) for command input. The local terminal is visible; physical keypad use, orientation and color accuracy are unqualified.

## Storage

Insert a microSD card before boot and leave it installed throughout the powered session; hot-swap is not supported. FAT32 and ext4 data-card reads and writes work in RAM sessions. The microSD system-card profile loads the kernel and an ext4 system root through the USB bootstrap. System-card file changes persist across power cycles. RAM files disappear when power is removed.

## Power and recovery

Under USB power with a read-only microSD system root, an RTC alarm can resume `s2idle`. Deep suspend, battery operation, other wake sources and the physical power-key action are unqualified.

Before disconnecting USB or removing the battery, [release data cards](/fplinux/use/power/#release-data-cards). If the phone stays powered, remove and reinsert its battery before booting normally. Follow [Run FPLinux](/fplinux/start/run/) to start a new session.

Feature support does not establish release readiness. See [Standalone archives](/fplinux/guides/standalone-archive/).
