## Before you start

The RAM launcher prepares [device data](/fplinux/guides/device-data/) from this same handset for Bluetooth, FM radio and its audio settings. Do not substitute data from another phone.

## Controls and storage

[Terminal](/fplinux/use/terminal/) describes the shared controls. Insert a microSD data card before boot and leave it installed throughout the powered session; hot-swap is not supported. RAM files disappear when power is removed.

## Power

Use the shared [Power](/fplinux/use/power/) interfaces within the checklist conditions.

## End the RAM session

[Unmount data cards](/fplinux/use/power/#unmount-data-cards) before disconnecting USB. If a battery is installed, remove and reinsert it before booting the phone normally.

## Hardware details and limits

- **Backlight**: system levels 0–10, with level 0 turning the light off. Visible spacing between levels is unverified. The target uses `/sys/class/backlight/maxvi-k15n-4g-backlight`.
