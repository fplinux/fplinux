## Install an optional application

Install the APK as described in [Packages](/fplinux/guides/packages/). In a
RAM boot, an installed application lasts until the phone shuts down. On a
[microSD system card](/fplinux/guides/microsd-system-card/), it stays installed
until you remove it. No optional application starts by itself. Exit an
application before you remove its package.

## Start an application

Start an application in either of two ways:

- On the phone, type its command in the [local terminal](/fplinux/use/terminal/).
- From the PC, run its command on the phone with `--exec`, as described in
  [Connect from a PC](/fplinux/use/connect/). The PC command returns when the
  application exits and shows its output.

Brightness control, ARMADA and TyrQuake take over the display while they run.
When they exit, the display returns to the terminal. `fplinux-present` and the
`fplinux-rotate` preview take over the display only while they show a picture.

## Command-line behavior

The FPLinux image tools, brightness application, ARMADA and Quake launcher
follow these command-line rules. FFmpeg uses its own syntax; see
`ffmpeg -h` for help.

- `-h` or `--help` prints the usage and every option, then exits with status
  `0`. It does not open a device or start any work.
- An option value can follow a space or an equals sign: `--output FILE` and
  `--output=FILE` are the same. Values cannot be empty.
- The image tools accept a repeated value option and use its last value. Every
  occurrence must still be valid. The other applications reject a repeated
  option.
- A command-line error prints the command name and the problem, followed by a
  hint, and exits with status `2`:

  ```text title="Phone"
  $ fplinux-present --input /run/frame.nv16 --mode rgb
  fplinux-present: --mode must be nv16 or cpu-rgb565
  Try 'fplinux-present --help' for more information.
  ```

- A failure after the command line has been accepted exits with another
  nonzero status and reports the cause on standard error.

## Where to keep files

Keep inputs and outputs in `/run` or `/tmp`. Both are RAM filesystems: they are
always writable, but they use phone memory and are emptied when the phone shuts
down. Copy files between the PC and the phone as described in
[Connect from a PC](/fplinux/use/connect/). To keep files across boots, use a
[microSD card](/fplinux/use/microsd/).
