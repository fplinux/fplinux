Java and MRE support come as optional packages. Follow [Optional packages](/fplinux/guides/packages/) to install the package for your files, together with its required APKs from the same build. MRE also needs `fplinux-font-terminus-8x16.apk` when that font is not already installed on the phone.

| Files | Package | Application |
| --- | --- | --- |
| Java MIDlet `.jar` | `fplinux-phoneme.apk` | phoneME |
| MRE `.vxp` | `fplinux-mre.apk` | MRE |

After installation, open **phoneME** or **MRE** from the application menu. Choose **Open** to browse My files or a memory card, or choose a previously opened program from **Recent**. You can also select a JAR or VXP directly in [Files](/fplinux/use/files/). A missing file stays in Recent so you can reconnect its card; removing that entry does not delete the program or its saved data.

Transfer your program to My files or a connected memory card. For uploads to My files, follow the [ownership step](/fplinux/use/connect/#files-for-graphical-applications) before opening it. Keep any companion files beside the program when it expects them there.

Use the [shared application controls](/fplinux/use/session/#home-and-applications) to return Home, resume a program from Tasks or close it. Closing a program opened from Files returns to its folder. Close programs using a memory card before [safely ejecting it](/fplinux/use/microsd/#remove-the-card-safely).

Choosing the runtime's tile again opens its home screen and pauses the current program. Choose **Continue** to return to it. Resuming from Tasks returns directly to the program. Neither action starts a second copy.

## Display settings

Open **Settings** on the runtime's home screen. With no program running, this opens the defaults for all programs. With a program running, choose **This program** or **All programs**. Each setting opens a list of values; choosing a value applies and saves it immediately, then returns to Settings. **Reset** in This program removes its overrides and uses the current defaults.

**Scale → Fit** preserves the image's proportions, **1:1** centres it without scaling and clips any part outside the screen, and **Integer** uses whole-number enlargement or reduction. **Rotation** changes the image and directional controls together. These settings apply to the running image.

phoneME also offers **Size**: **Auto** uses the phone's available area; the other choices are 128×128, 128×160, 176×208, 176×220, 240×320 and 320×240. Choose a size that suits the program; its filename does not select one. A Size change takes effect the next time the Java program starts. MRE keeps its existing guest display size and offers **Pointer → Off / On** for programs that support pointer input.

If saving fails, the chosen value remains applied and Settings shows **Unsaved** with an error message. Choose the value again to retry saving. A successful save in another settings scope does not clear the failed scope's marker. Settings follow the [home directory's lifetime](/fplinux/use/files/); a successful save during RAM boot does not preserve them after power-off.

## Java programs

Open the JAR itself. When it contains several MIDlets, choose the one to run. Opening another JAR asks to close the current program; cancel to keep it running.

Java programs using FileConnection access My files as `c:/` and a mounted data card as `e:/`. PhoneME supports listing, reading and writing files in these folders. A program that depends on notifications when a storage root is added or removed may need to be reopened to find the card.

Java record stores remain after closing and reopening phoneME. Programs with the same **MIDlet-Vendor** and **MIDlet-Name** share their records across version updates and moves to another folder. A program missing either field uses its JAR path instead: moving it gives it a separate store. Different suites keep separate records.

Records live in your home directory. During a RAM boot, they survive closing the application but are lost when the phone loses power. A memory card containing the JAR does not make these records persistent. See [Files](/fplinux/use/files/) for the home directory's lifetime.

## MRE programs

MRE programs can use two drive names:

| Drive | Location |
| --- | --- |
| `E:` | The folder containing the VXP and its companion files |
| `C:` | Private files for that program in your home directory |

`E:` can be on a memory card or in My files. `C:` follows the [home directory's lifetime](/fplinux/use/files/): it is lost at power-off in a RAM boot. Renaming or moving the VXP gives it a different private store; replacing the program at the same path retains that store.

Opening another VXP asks before replacing the running program. Cancel keeps the current program and its pending input. MRE graphics use a 240×320 surface scaled to fit the phone's display.

MRE currently ends a program after 15 minutes, or after it uses two minutes of CPU time. Save through the program's own controls before closing it; closing the runtime does not save unfinished work for the program.

## Compatibility

Support depends on the APIs each program uses. A JAR or VXP extension alone does not establish compatibility. A program that needs unsupported APIs can fail to open or stop while running. Neither runtime installs or modifies the phone's original firmware.

PhoneME supports common Nokia drawing and sound operations, AMR-NB speech effects through MMAPI, MascotCapsule micro3D v3 rendering, and a subset of JSR 184 Mobile 3D Graphics (M3G). M3G support covers cameras, textured meshes with one texture per surface, animated bones, morphing vertex positions and normals, and camera-facing sprites. Compatibility and frame rate vary by game.
