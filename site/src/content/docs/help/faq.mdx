## Using the phone

### Can I make calls, send SMS or use mobile data?

No. FPLinux does not use the phone's modem, so calls, SMS and mobile data do not work. For Internet access on the phone, share a connection over [Bluetooth](/fplinux/use/bluetooth/#internet-over-bluetooth-pan), or use Wi-Fi where your [phone page](/fplinux/phones/) lists support.

### Does FPLinux stay on the phone?

No. Every start loads FPLinux from a PC over USB, and the default system runs from RAM and forgets everything at power-off. A [microSD system card](/fplinux/guides/microsd-system-card/) keeps files and installed packages between sessions, but each cold start still needs the PC. FPLinux cannot be installed to the phone's internal storage.

### Will the phone still work as before?

Yes. Starting the phone normally, without the boot key, starts its own firmware. See [Power](/fplinux/use/power/#return-to-the-phones-own-firmware).

### Can I use the phone without a computer?

Once Linux runs, use the [phone interface](/fplinux/use/session/) on phones with supported display and keypad input. Use the USB shell for commands and when physical input is not tested. Starting FPLinux always needs a PC, and the phone needs USB power when it has no battery. Check your [phone page](/fplinux/phones/) for its limits.

### Does it work on my phone?

Only on the [supported phones](/fplinux/phones/). A target describes one exact model, so do not use it for a different phone, even one with the same chip. If your keypad phone uses the Unisoc UMS9117, create a headless target and try [bring-up](/fplinux/porting/bring-up/). The [new-phone checklist](/fplinux/porting/checklist/) explains what to establish.

### Is there Wi-Fi?

Wi-Fi station and access-point modes are supported on [BQ 2830L Tank Connect Max](/fplinux/phones/bq-2830l-tank-connect-max/). Check that phone's limits; Wi-Fi is not supported on the other current targets.

### Does it show the battery level?

The graphical interface shows an estimated battery icon where readings are available. It is not a calibrated battery percentage and does not establish charging support. Battery voltage, current and a relative charge counter are available where the phone supports battery telemetry. Check its checklist for availability and accuracy limits. See [Charger and battery](/fplinux/use/power/#charger-and-battery).

### Can I install more software?

You can install the [optional packages](/fplinux/guides/packages/) built with your image. FPLinux configures no package repository on the phone.

## Your computer

### What do I need on my computer?

Building from source needs a Linux x86-64 PC with Python 3.14 and network access for the first build. Running your build uses the tools listed in [Run FPLinux](/fplinux/start/run/#before-you-start). A [standalone archive](/fplinux/guides/standalone-archive/) lists its host requirements and bundles its runtime for Linux x86-64 or Windows 10/11 x64.

### Do I need Docker or Podman?

No. `./fplinux setup` installs the build environment inside the checkout. Builds and source checks use it from there. See [Build FPLinux](/fplinux/start/build/).

### Can I run FPLinux without building it?

A [standalone archive](/fplinux/guides/standalone-archive/) runs FPLinux without a source checkout. That guide explains how to use a ZIP you received and where to obtain or create one.

On [GitHub](https://github.com/fplinux/fplinux). [Where the code is](/fplinux/develop/contributing/#where-the-code-is) explains the layout, and pages about a phone, an application or a feature link to their source under the page title.
