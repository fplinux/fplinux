FPLinux is an open-source Linux system for keypad phones built on the Unisoc UMS9117 and SC9820E chips. It provides a graphical phone interface and a shell from your computer. Depending on the phone, it also supports sound, FM radio, Bluetooth and microSD cards.

## How it works

<div class="fp-grid-3">
<Card title="1. Prepare" icon="laptop">

If you received a ZIP for your phone, [extract it and use its launcher](/fplinux/guides/standalone-archive/). To create your own image, [build from source on Linux](/fplinux/start/build/).

</Card>
<Card title="2. Start" icon="mobile-android">

Start the launcher and wait for its instructions before connecting the powered-off phone with its boot key held. From a source checkout, use [Run FPLinux](/fplinux/start/run/).

</Card>
<Card title="3. Use" icon="seti:shell">

Open applications and settings on the phone. [Phone interface](/fplinux/use/session/)

</Card>

</div>

FPLinux runs from the phone's RAM. To keep files and installed packages between sessions on a supported phone, boot from a [microSD system card](/fplinux/guides/microsd-system-card/). FPLinux cannot be installed to the phone's internal storage.

## What you get

The [feature overview](/fplinux/features/) separates implementation from device checks. Your phone's checklist records its supported functions and limits.

<CardGrid>
<Card title="Phone interface" icon="mobile-android">

Home, an application catalog, task switching, Settings, Terminal, Notes and Snake. [Phone interface](/fplinux/use/session/)

</Card>
<Card title="Your computer, connected" icon="laptop">

A shell over USB, file copies and your PC keyboard on the phone. [Connect from a computer](/fplinux/use/connect/)

</Card>
<Card title="Sound and FM radio" icon="seti:audio">

Headphones, speaker, microphone and FM radio, depending on the phone. [Sound](/fplinux/use/audio/) · [FM radio](/fplinux/use/fm-radio/)

</Card>
<Card title="Bluetooth" icon="link">

Pairing, file transfer and Internet over Bluetooth. Optional SBC audio playback is verified with a Linux PC receiver on selected phones. [Bluetooth](/fplinux/use/bluetooth/)

</Card>
<Card title="microSD system card" icon="seti:folder">

A persistent system on a card that keeps files and packages. [System card](/fplinux/guides/microsd-system-card/)

</Card>
<Card title="Apps and packages" icon="puzzle">

Built-in graphical applications, a showcase, TyrQuake, image tools and optional FFmpeg. [Applications](/fplinux/apps/)

</Card>

</CardGrid>

## What you need

- One of the phones above and a USB data cable.
- For a ready ZIP: a Linux x86-64 or Windows 10/11 x64 PC, as listed in its [requirements](/fplinux/guides/standalone-archive/#what-you-need). Windows USB loading and SSH remain unverified with Qin 1s+.
- To build from source: a Linux x86-64 PC with Python 3.14 and network access for the first build.
